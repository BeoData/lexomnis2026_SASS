# Laravel TDD Workflow

## Core Rules
- 80%+ coverage.
- Use `RefreshDatabase` trait.
- Feature tests for HTTP/Inertia.
- Unit tests for Services/Actions.
- Fakes for Mail, Bus, Queue, Events.
